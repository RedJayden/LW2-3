# 설계 문서: LASERnGRAPN (LW23)

이 문서는 `LASERnGRAPN` 프로젝트의 아키텍처, 기술 스택, 개발 워크플로우 및 핵심 기능에 대한 분석을 제공합니다.

## 1. 프로젝트 개요 (Overview)

`LASERnGRAPN`은 C++로 작성된 네이티브 호스트와 React 기반의 웹 UI를 결합한 하이브리드 데스크톱 애플리케이션입니다. 이 구조는 네이티브 코드의 성능과 하드웨어 접근성의 이점, 그리고 웹 기술을 이용한 신속하고 유연한 UI 개발의 장점을 모두 활용합니다.

- **네이티브 호스트 (`LASERnGRAPN`):** Win32 API와 Chromium Embedded Framework (CEF)를 사용하여 메인 윈도우를 생성하고 웹 기반 UI를 호스팅합니다. 하드웨어 제어, 비전 시스템 연동 등 저수준(low-level) 작업을 담당합니다.
- **웹 UI (`Portal`):** CEF 웹뷰 내에서 실행되는 단일 페이지 애플리케이션(SPA)입니다. React, TypeScript, Vite를 기반으로 구축되었으며, 애플리케이션의 모든 사용자 인터페이스를 제공합니다.

## 2. 아키텍처 (Architecture)

프로젝트는 기능적으로 분리된 여러 하위 프로젝트로 구성된 모노레포 구조를 가집니다.

![Architecture Diagram](https://user-images.githubusercontent.com/12575835/189792589-b0363373-3993-4a1d-99f4-348d7ad1036b.png)
*(위 이미지는 일반적인 CEF 기반 하이브리드 앱 아키텍처 예시입니다.)*

1.  **Native Host (C++):**
    -   `LASERnGRAPN.exe`는 애플리케이션의 진입점입니다.
    -   CEF를 초기화하고 `Portal` 프로젝트의 빌드 결과물(`index.html`)을 로드하여 웹뷰를 생성합니다.
    -   UI와 네이티브 코드 간의 통신을 위한 IPC(Inter-Process Communication) 브릿지를 설정합니다.
    -   `VisionModule.dll`과 같은 동적 라이브러리를 로드하여 머신 비전 기능을 확장합니다.

2.  **Web UI (React/TypeScript):**
    -   `Portal` 디렉토리에 위치한 React 프로젝트입니다.
    -   Vite를 빌드 도구로 사용하여 개발 서버 실행 및 프로덕션 빌드를 수행합니다.
    -   UI의 모든 상태는 Zustand를 사용하여 중앙에서 관리됩니다.
    -   Material-UI와 Tailwind CSS를 함께 사용하여 UI 컴포넌트를 구성합니다.

3.  **Communication Layer (IPC):**
    -   **핵심 원리:** 프론트엔드(JavaScript)와 백엔드(C++) 간의 통신은 스키마 기반의 IPC 메커니즘을 통해 이루어집니다.
    -   **스키마 정의:** `Portal/ipc/channels.schema.json` 파일에 통신에 사용될 모든 채널(명령 및 이벤트)의 이름, 파라미터, 반환 타입을 JSON 형식으로 정의합니다. 이것이 통신의 **Single Source of Truth** 역할을 합니다.
    -   **코드 자동 생성:** `npm run gen:ipc` 스크립트를 실행하면, 위 스키마 파일을 읽어 TypeScript와 C++ 코드를 자동으로 생성합니다.
        -   `Portal/src/core/ipc/channels.gen.ts`: 프론트엔드에서 사용할 타입-세이프(type-safe) 함수들.
        -   `LASERnGRAPN/Core/Communication/ChannelHandlers.gen.cpp` (가상 경로): C++ 백엔드에서 요청을 처리할 핸들러 템플릿.
    -   **데이터 흐름:**
        1.  React 컴포넌트에서 자동 생성된 `ipc.app.quit()`과 같은 함수를 호출합니다.
        2.  CEF의 JavaScript 바인딩을 통해 이 호출이 C++ 호스트로 전달됩니다.
        3.  C++의 `PortalRouterHandler`가 채널 이름을 기반으로 적절한 핸들러 함수를 찾아 실행합니다.
        4.  처리 결과는 Promise를 통해 다시 JavaScript로 비동기적으로 반환됩니다.

4.  **Vision System (`VisionModule.dll`):**
    -   카메라 제어, 이미지 처리 등 모든 머신 비전 관련 기능이 포함된 C++ DLL입니다.
    -   OpenCV, HikRobot SDK 등을 사용하며, Strategy 패턴을 통해 여러 종류의 카메라 SDK를 쉽게 교체하거나 추가할 수 있도록 설계되었습니다.
    -   **MJPEG 스트리밍:** 고성능 비디오 스트리밍을 위해 IPC와는 별개의 채널을 사용합니다. `VisionModule`은 내부적으로 MJPEG 스트림 서버 역할을 하고, 프론트엔드는 `app://camera/stream`과 같은 커스텀 프로토콜 주소를 `<img>` 태그의 `src`로 사용하여 비디오를 수신합니다. 이 방식은 IPC 채널에 과부하를 주지 않으면서 매우 낮은 지연 시간(low-latency)을 달성합니다.

## 3. 기술 스택 (Tech Stack)

-   **Backend (Native):** C++ (Win32), Chromium Embedded Framework (CEF)
-   **Frontend:** React, TypeScript, Vite, Zustand, Material-UI, Tailwind CSS
-   **Vision Module:** C++, OpenCV, Vendor SDKs (e.g., HikRobot)
-   **Build & Tooling:** Visual Studio (C++), Node.js/NPM (Frontend)

## 4. 폴더 구조 (Folder Structure)

-   `Bin/`: 최종 빌드 결과물(실행 파일, DLL, React 빌드 산출물 등)이 위치하는 디렉토리.
-   `LASERnGRAPN/`: 메인 C++ 애플리케이션 (네이티브 호스트).
    -   `Core/Communication/`: IPC 라우팅 및 핸들러 구현부.
-   `Portal/`: 프론트엔드 React 프로젝트.
    -   `src/`: React 소스 코드.
    -   `ipc/`: **`channels.schema.json`** (IPC 명세) 및 자동 생성 스크립트.
    -   `tools/`: `generate-ipc.cjs` 등 개발 워크플로우 스크립트.
-   `VisionModule/`: C++ 머신 비전 DLL 프로젝트.

## 5. 핵심 개발 워크플로우 (Key Development Workflow)

새로운 기능을 추가하는 일반적인 과정은 다음과 같습니다.

1.  **IPC 스키마 정의:** `Portal/ipc/channels.schema.json`에 새로운 명령(command)이나 이벤트(event)를 추가/수정합니다.
2.  **코드 자동 생성:** `Portal` 디렉토리에서 `npm run gen:ipc`를 실행하여 TypeScript와 C++ 양쪽의 통신 코드를 동기화합니다.
3.  **프론트엔드 구현:** `Portal/src/` 내의 React 컴포넌트에서 자동 생성된 IPC 함수를 사용하여 네이티브 기능을 호출하는 UI 로직을 작성합니다.
4.  **백엔드 구현:** `LASERnGRAPN/Core/Communication/PortalRouterHandler.cpp`와 같은 파일에 새로 추가된 IPC 채널에 대한 C++ 핸들러 로직을 구현합니다.
5.  **빌드 및 실행:** Visual Studio 솔루션을 빌드하여 C++ 코드를 컴파일하고, `npm run dev` (개발 시) 또는 `npm run build` (배포 시)를 실행하여 프론트엔드를 준비합니다. 최종적으로 `Bin/` 디렉토리에서 `LASERnGRAPN.exe`를 실행합니다.

## 6. 주요 기능 (Main Features)

-   **다축 모션 제어:** `motion.jog`와 같은 IPC 채널을 통해 기구부의 정밀 제어 기능을 제공 (현재 일부 기능은 구현 진행 중).
-   **통합 머신 비전:** 산업용 카메라 연동 및 OpenCV를 통한 이미지 프로세싱.
-   **실시간 비디오 스트리밍:** 저지연 MJPEG 스트림을 통한 카메라 영상 UI 표시.
-   **모던 하이브리드 UI:** 웹 기술로 구현된 유연하고 반응성 좋은 사용자 인터페이스.
