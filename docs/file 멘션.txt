4. 코드 가이드 및 절대 엄금 사항 (Anti-Patterns)
배율 하드코딩 절대 엄금: 소스 코드 전반에 baseScale = 1000과 같이 스캐너 배율을 고정 상수로 사용하는 잔재를 완전히 배제하고, 현재 렌더링 중인 카메라 스케일(activePxPerMm)을 동적으로 참조하십시오.

가공 중 도형 숨김 처리 금지: 가공 상태일 때 진행 상태 파악을 방해하는 visible = false 전환 코드를 작성하지 마십시오. 대신 선택 및 이벤트 속성(selectable = false, evented = false)만 차단하여 마우스 오작동을 방지하는 Read-Only 구조를 유지하십시오.

UI에서의 하드웨어 설정 변경 금지: 프론트엔드 비즈니스 로직 내부에서 직접 하드웨어 설정을 변경하고 저장하는 통신 블록(setMoonsConfig 등)을 추가하지 마십시오.
