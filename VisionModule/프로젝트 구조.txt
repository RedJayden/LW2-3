원하신다면 제가 Visual Studio에서 “**VisionModule → LatestFrameStore → CameraResourceHandler → Portal**” 까지
 JPEG 데이터가 흘러가는 **전체 경로(시퀀스 다이어그램)** 를 그려드릴 수도 있습니다.
 그걸 보시면 “어디서 Set되고 어디서 Get되는지” 한눈에 파악 가능합니다. 그거 원하시나요?

좋습니다. VisionModule → LatestFrameStore → CEF(AppScheme/ResourceHandler) → Portal(React) 로 흐르는 시퀀스 다이어그램과 구성도를 그려드릴게요.
(아래 Mermaid 코드는 그대로 붙여 넣어 미리보기 가능합니다.)

시퀀스: MJPEG 스트림 (app://camera/stream?id=<0|1|2>)
sequenceDiagram
    autonumber
    participant Cam as Camera Driver(Scanner/Object)
    participant VM as VisionBridge / CameraManager
    participant LFS as LatestFrameStore (0/1/2)
    participant CEF as CameraResourceHandler (/stream)
    participant Portal as Portal <img src=app://...>

    Cam->>VM: Grab raw frame (BGR/YUV/…)
    VM->>VM: JPEG encode
    VM->>LFS: SetJpeg(camId, jpegBytes)  **(FPS 누적/갱신)**
    Note right of LFS: slots[camId].buf = jpegBytes<br/>slots[camId].fps = frames/sec

    Portal->>CEF: GET app://camera/stream?id=camId
    CEF->>LFS: GetJpeg(camId)
    LFS-->>CEF: jpegBytes
    CEF-->>Portal: multipart/x-mixed-replace; boundary=frame<br/>--frame\r\nContent-Type:image/jpeg…<br/>(jpegBytes)<br/>\r\n--frame…
    loop 반복 (프레임마다)
        CEF->>LFS: GetJpeg(camId)
        LFS-->>CEF: jpegBytes
        CEF-->>Portal: 다음 파트 전송 (chunk)
    end

시퀀스: 스냅샷 (app://camera/frame.jpg?id=<id>)
sequenceDiagram
    participant Portal as Portal (fetch)
    participant CEF as CameraResourceHandler (/frame.jpg)
    participant LFS as LatestFrameStore

    Portal->>CEF: GET app://camera/frame.jpg?id=camId
    CEF->>LFS: GetJpeg(camId)
    LFS-->>CEF: jpegBytes
    CEF-->>Portal: 200 OK + Content-Type:image/jpeg (단발 응답)

시퀀스: FPS (app://camera/fps?id=<id>)
sequenceDiagram
    participant Portal as Portal (fetch JSON)
    participant CEF as CameraResourceHandler (/fps)
    participant LFS as LatestFrameStore

    Portal->>CEF: GET app://camera/fps?id=camId
    CEF->>LFS: GetFps(camId)
    LFS-->>CEF: double fps
    CEF-->>Portal: 200 OK + {"fps": <value>}

구성(컴포넌트) 다이어그램
graph LR
    subgraph Native
        Cam[Camera Driver<br/>(Basler/HIK/…)]
        VM[VisionBridge / CameraManager<br/>JPEG encode + push]
        LFS[(LatestFrameStore<br/>slots[0..2]: buf,fps)]
        CEF[CEF AppScheme + CameraResourceHandler<br/>/stream, /frame.jpg, /fps]
    end

    subgraph Portal (React)
        UI[CameraStream.tsx <img>]
        FPS[useCameraFps.ts]
    end

    Cam --> VM --> LFS
    UI -- GET app://camera/stream?id --> CEF
    FPS -- GET app://camera/fps?id --> CEF
    CEF --> LFS
    CEF -- JPEG/MJPEG/JSON --> UI
